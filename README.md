# 🧠 PathFinder — Smart Resume & Job Match Analyzer  
![python](https://img.shields.io/badge/Built%20With-Python-FFD43B?style=for-the-badge&logo=python&logoColor=black)
![streamlit](https://img.shields.io/badge/Frontend-Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)

PathFinder is an web app built with **Streamlit** that analyzes your resume, extracts skills, compares them with job descriptions, recommends courses, generates PDF reports, and keeps personalized user history — all with a login system & profile panel.

---

## 🚀 Features  

### 🔐 **User Authentication**
- Login & Register system  
- Persistent user storage  
- Per-user data & settings  

### 👤 **Personalized User Dashboard**
- Profile icon + username  
- Per-user history (like ChatGPT)  
- Clear history option  
- Secure logout  

### 📄 **Resume & Job Analyzer**
- Extracts skills from **PDF / DOCX resumes**  
- Extracts skills from Job Descriptions  
- Calculates:
  - Matched skills  
  - Missing skills  
  - Match percentage  

### 📚 **Course Recommendations**
Uses your missing skills to suggest **Coursera** & **Udemy** courses.

### 📊 **Visual Reports**
- Bar charts (Resume vs Job vs Matched skills)  
- Donut chart for skill match distribution  
- Clean skill comparison tables  

### 📥 **PDF Report Generation**
- Auto-generated professional PDF  
- Includes skills, analysis, and course recommendations
